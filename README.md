# تطبيق حسابات ومخزن محل الحديد والمواد (PWA)

تطبيق ويب تقدمي (PWA) بسيط وسريع ومصمم خصيصاً لأصحاب محلات الحديد والعدد اليدوية والمسامير. يعمل 100% بدون إنترنت ومناسب للاستخدام على الهواتف الذكية والأجهزة المكتبية باللغة العربية (RTL).

---

## مميزات التطبيق الأساسية
1. **أصناف غير محدودة مع تنبيهات النفاذ**: إدارة مخزن المسامير، العدد، والكهرباء مع حد تنبيه تلقائي.
2. **شاشة بيع سريع (POS)**: مصممة للأجهزة اللوحية والهواتف بلمسة واحدة وسلة مبيعات فورية.
3. **فواتير نقدية وآجلة**: دعم الدفع الجزئي وتتبع ديون العملاء تلقائياً.
4. **الحسابات وديون العملاء والموردين**: إمكانية إرسال تذكير بالديون عبر WhatsApp بنقرة واحدة وكشف حساب مفصل.
5. **التقارير اليومية والأسبوعية والشهرية**: حساب المبيعات، الأرباح، المصاريف، وصافي الربح مع إمكانية التصدير لـ Excel (CSV).
6. **إقفال اليوم (Daily Close)**: مطابقة النقدية الفعلية بالدرج مع المتوقعة.
7. **النسخ الاحتياطي والاستعادة**: تصدير واستيراد قاعدة البيانات بملف واحد JSON للحفاظ على البيانات آمنة.
8. **يعمل بدون إنترنت (Offline-first)** مع تخزين آمن في IndexedDB.

---

## خطوة (أ): كيفية رفعه على GitHub Pages (مجاناً)
1. قم بإنشاء حساب جديد على [GitHub](https://github.com) إذا لم يكن لديك حساب.
2. أنشئ مستودع (Repository جديد) وليكن باسم `hardware-shop`.
3. ارفع كافة ملفات المشروع الموجودة في هذا المجلد إلى المستودع الرئيسي:
   - `index.html`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
4. من داخل إعدادات المستودع في GitHub، اذهب إلى قسم **Pages**.
5. تحت قسم **Build and deployment**، اختر الفرع `main` (أو `master`) واضغط **Save**.
6. بعد دقائق قليلة، سيظهر لك رابط الموقع (مثل `https://yourusername.github.io/hardware-shop`). افتحه من هاتفك المحمول واضغط على خيار **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ليعمل كتطبيق مستقل (PWA).

---

## خطوة (ب): تحويل التطبيق إلى تطبيق Android (APK) عبر PWABuilder
1. اذهب إلى موقع [PWABuilder](https://www.pwabuilder.com/).
2. الصق رابط موقعك على GitHub Pages في خانة البحث واضغط **Start**.
3. سينتهي الموقع من فحص التطبيق ويعطيك تقريراً، اضغط على زر **Generate** تحت قسم **Android** (توليد تطبيق Android).
4. املأ البيانات المطلوبة (اسم التطبيق، اسم الحزمة Package Name، إلخ) ثم حمّل الحزمة الموقعة (Signed APK / AAB).
5. يمكنك الآن تثبيت ملف الـ APK مباشرة على أي هاتف Android للاستخدام كتطبيق محلي كامل!
